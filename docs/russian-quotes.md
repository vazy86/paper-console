# Подготовка русских цитат для Daily Quote

Источник: пользовательский файл motiviruyushchie_tsitaty_150.txt. Исходник не изменён.

- В исходнике 149 записей, отсутствует номер 15.
- В подготовленном JSON 146 записей. Точных повторов после нормализации регистра и Ё/Е нет; смысловые повторы возможны.
- Исключены 97 и 149 (обрывы), 138 (английская игра слов не работает на русском).
- У 25 и 145 удалено завершающее тире без автора. Авторы не придуманы.
- Поля quoteText и quoteAuthor соответствуют формату Daily Quote; sourceNumber и attributionStatus сохраняют происхождение и статус атрибуции.
- Все указанные авторы перенесены из файла и не проверены по первоисточникам.
- Дополнительная редакторская проверка нужна как минимум для 45 (согласование), 84 (согласование), 89 (разорванная конструкция), 136 (возможно сокращённая цитата). Их текст сохранён без домысливания.
- Daily Quote поддерживает language=en/ru, по умолчанию en. При каждой печати выбирается случайная цитата; интернет не нужен. Пользовательское название модуля сохраняется.
- Развёртывание на Raspberry Pi выполняется отдельно.
